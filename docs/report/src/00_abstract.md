Intrusion detection improves when a model learns from traffic seen by many organizations, yet network flow records are seldom allowed to leave the organization that captured them. Federated learning answers part of this problem: each organization trains locally and shares only model weights. This project asks what happens after that step. We built XFed-IDS-ByzAgent, a federated intrusion detection system that also tests whether its own explanations agree across participants and whether any participant can be trusted.

The system has five stages. The corrected Distrinet release of CICIDS2017 is cleaned into eight attack families and a Benign class. Ten simulated organizations then train a shared multilayer perceptron with FedAvg under three levels of label skew, set by a Dirichlet parameter α of 0.1, 0.5 and 5.0, with three seeds each. Test macro-F1 is 0.516 ± 0.048, 0.941 ± 0.057 and 0.990 ± 0.001 at the three skew levels, against 0.9900 ± 0.0022 for a centralized model.

The explanation check compares each organization's SHAP feature ranking with the global model's ranking. Median Jaccard@10 falls from 0.667 to 0.538 to 0.333 as skew grows. We read every value against two references: the chance level, 0.065, and a seed-noise floor of 0.429, which is the agreement between centralized models that differ only in their random seed. At α=0.1 the agreement sits under that floor, but the bootstrap intervals overlap, so this result is directional, not significant.

The trust check is a separate experiment. A worst-case label-flipping attack is run, and a locally hosted language-model agent, ByzAgent, reads five per-organization statistics each round and chooses to trust, downweight or quarantine. Classical robust rules mostly reacted to how unusual an organization's data was: Multi-Krum excluded a malicious silo 0% of the time. ByzAgent also responded to silo composition, and showed attack-responsive flags where flag rates were not already saturated. It produces decisions plus a rationale of measured fidelity. A FastAPI and React dashboard brings detection, explanations and trust decisions together on one screen.
